# Tasks

Conventions used below:
- `<base>` is the commit this change starts from; task 1.1 records it before any edit.
- `<scratch>` is a folder outside the repository. Hashes, listings and screenshots go there, never into the repository.
- `$PW` stands for `npx -y -p playwright@1.63.0 -p tsx@4.23.15 tsx`, and `$TSX` for `npx -y -p tsx@4.23.15 tsx`.
- The four cat images are `4d-os`, `4d-os-a`, `4d-os-b` and `4d-os-c`; the six others are `museum`, `bloomscope`, `game-center`, `wind-up-empire`, `4d-os-d` and `4d-os-e`.
- No capture is taken and no server is needed: only `compose` runs (design D5). No page HTML, no file under a museum sheet's `sources` and no `package.json` changes.
- Commits follow Conventional Commits, `type(scope): subject`, with no co-author or tool trailer. Nobody deploys or pushes.
